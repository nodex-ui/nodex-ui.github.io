# Progress

## Nodex UI component

```js
import { Progress } from "nodexui";
```

```base-ui
<div style="width: 60%">
  <Progress value="33"/>
</div>
```

| Component | Prop | Type | Notes |
| --- | --- | --- | --- |
| `Progress` | `value` | `Number` | optional |
| `Progress` | `max` | `Number` | optional |
| `Progress` | `className` | `String` | optional |

See [Nodex UI Component](/index.html#/docs/guide/owl-components) for how to load `nodexui` and `dist/nodexui.templates.xml`.

## Static component

```base-ui
<div b-ui="progress" b-att-value="40"></div>
```
